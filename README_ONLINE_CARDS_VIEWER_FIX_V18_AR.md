# IDRIS Schools V18 - إصلاح كروت الأونلاين والعرض الداخلي

رقم النسخة: 1.0.18+18

التعديلات في التطبيق فقط:

- إضافة دعم WebView في معاينة FlutLab/Web بإضافة `webview_flutter_web` حتى لا يظهر خطأ `WebViewPlatform.instance`.
- فتح عارض الملفات باستخدام HTML داخلي بدل Data URI لتقليل مشاكل التحميل.
- كل العناصر تفتح داخل التطبيق حتى لو كانت معلومات بدون ملف.
- إضافة كل كروت طالب الأونلاين مثل المنصة:
  - جدول الحصص
  - الحصص المباشرة
  - التسجيلات
  - المحتوى التعليمي
  - بنك الأسئلة
  - الاختبارات
  - الأنشطة والواجبات
  - الحضور
  - المناقشات
  - الإعلانات
  - الإشعارات
  - النتائج

ملاحظة: حتى تظهر الكروت الجديدة بداتا حقيقية لازم ترفع باتش `mobile_api` الجديد داخل المنصة.
