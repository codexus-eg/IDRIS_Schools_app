# تحديث IDRIS Schools 1.0.17+17

تم تنفيذ المطلوب فوق آخر نسخة GitHub Actions المعتمدة بدون تغيير ERP:

1. كل ملفات المحتوى تفتح داخل التطبيق عبر عارض داخلي WebView:
   - PDF
   - PNG / JPG / WEBP
   - PowerPoint / Word / Excel
   - فيديوهات MP4 / Drive / YouTube
2. عرض صورة/غلاف المحتوى بجانب الملف عند وجودها.
3. إضافة دخول طالب أونلاين بنفس username/password الخاص بمنصة الأونلاين.
4. جلب محتوى منصة الأونلاين Live حسب صف الطالب:
   - محتوى المنصة
   - فيديوهات المنصة
   - تسجيلات الحصص
   - الأنشطة والواجبات
   - الاختبارات
   - الإعلانات
5. عرض ملفات منصة الأونلاين وملفات Google Drive داخل التطبيق.
6. الطالب يرى تعليقات ولي الأمر وطلبات الإجازة والردود عليها.
7. المشرف يرد على تعليقات ولي الأمر من التطبيق.

## مهم قبل البناء

ارفع باتش داش بورد التطبيق داخل `app-dashboard`.
وارفع باتش منصة الأونلاين داخل `/ar`.
ثم ابنِ AAB من هذه النسخة لأنها أصبحت `1.0.17+17` ومناسبة للـ Production بعد `1.0.16`.
