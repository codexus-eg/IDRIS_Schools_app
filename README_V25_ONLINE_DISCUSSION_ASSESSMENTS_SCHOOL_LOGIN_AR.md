# IDRIS Schools V25

هذا الإصدار مبني فوق V24 بدون كسر طريقة عرض الملفات التي نجحت سابقاً.

## ما تم تنفيذه

- لم يتم لمس منصة الأونلاين الأساسية أو تصميمها.
- لم يتم تغيير طريقة عرض PDF والفيديو الناجحة.
- إضافة مناقشات الأونلاين داخل التطبيق: عرض المنشورات والردود + إضافة منشور + إضافة رد + مرفقات.
- إضافة حل الاختبارات/الكويز داخل التطبيق سؤال بسؤال.
- أزرار: السابق / التالي / حفظ / تسليم الاختبار.
- دعم إجابات MCQ و True/False و Short Text و Long Text.
- دعم رفع ملف/صورة لإجابات الأسئلة الطويلة أو اختبارات ملف السؤال.
- إصلاح دخول طالب المدرسة بالسيريال والرقم عبر باتش الداش بورد المرفق.
