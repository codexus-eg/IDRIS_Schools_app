# مشروع مؤسسة إدريس — نسخة FlutterLab الكاملة

هذه النسخة مشروع Flutter كامل وليست ملفات صفحة فقط. المجلد الجذري داخل ZIP يحتوي مباشرة على:

- `android/`
- `assets/`
- `lib/`
- `pubspec.yaml`
- `.metadata`

لذلك يمكن رفع ملف ZIP مباشرة من خيار **Upload as a ZIP file** في FlutterLab.

## الموجود في النسخة

- أيقونة Android عادية وتكيفية.
- شاشة Android الأصلية قبل تشغيل Flutter لمنع ظهور شاشة بيضاء.
- شاشة Splash متحركة مكتوبة بدارت.
- كل جزء في ملف منفصل.
- صفحة مؤقتة بعد Splash، يتم استبدالها بصفحة الدخول في الخطوة القادمة.

## معرّف التطبيق الحالي

`com.idrisschool.app`

## ملاحظة النشر

إعداد Release الحالي يستخدم debug signing فقط حتى يعمل الاختبار. قبل رفع AAB إلى Google Play سنضيف ملف التوقيع النهائي بطريقة آمنة.


## النسخة المصححة لـ FlutterLab
- يحتوي جذر المشروع على `android/`.
- يحتوي جذر المشروع على `ios/` وبنية Xcode كاملة.
- يحتوي كذلك على `web/` لتفادي أخطاء المنصات المتتابعة.
- ارفع ملف ZIP نفسه ولا تفك الضغط قبل رفعه إلى FlutterLab.
